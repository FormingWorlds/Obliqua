Get started

The Obliqua documentation follows the Diataxis framework: How-to guides for specific tasks, Tutorials for learning by doing, Explanations for understanding the design, and Reference for looking up details. You can find all sections in the sidebar.

Quick path

  1. Install Obliqua: set up the code and required dependencies. ➔ Installation guide
  2. Run a simple example: calculate tidal Love numbers for a simple planet-mantle model. ➔ Quick start tutorial
  3. Run a more complex example: simulate a multi-phase radially resolved tidal dissipation model. ➔ Science examples
